# Broad Board

An 8×8 two-color tile puzzle.

**How to play**
- Hover a tile to highlight a 2×2 block
- Click to rotate that block 90° clockwise
- Choose a target pattern from the dropdown and match the preview
- Use **Randomize** for a new scramble

**Play online**  
https://jorobertmac.github.io/broadboard/

Built as a lightweight vanilla HTML/CSS/JS web app.
